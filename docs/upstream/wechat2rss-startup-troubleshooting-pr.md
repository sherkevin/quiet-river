`docs: distinguish image download errors from license startup failures`

## 正文

在 Docker Hub 访问超时和干净数据目录下的授权失败排查中，发现现有文档可以补充几处容易混淆的操作。此 PR 只修改 `deploy/qa.md`，不修改软件、镜像或授权机制。

补充内容：

- 镜像下载失败与程序启动失败分开诊断，并链接已有官方备用镜像源说明。
- 切换源时同时修改 Compose 的 `image`，避免只 pull 备用镜像后仍从原地址启动。
- 说明 v1.4.9 的 `need license` 与授权拒绝错误，并链接授权配置、激活和微信登录文档。
- 提醒排错日志含管理密码，不能公开完整日志或展开后的 Compose 配置。
- 区分 `up -d` 重新创建与 `restart`，解释环境变量持久化不等于免授权。
