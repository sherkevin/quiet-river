# 博主、文章、未读与后台

本批按 2026-09-17 用户追加需求实现，不改变来源采集和授权范围。

## 导航与标签

- 原“来源接入”改为“博主”，原“全部更新”改为“文章”。
- 新增“未读”和“后台”；保留已有阅读器、日报及其他入口。
- 博主行提供标签编辑器，可添加、移除、清空标签并保存。
- 新文章首次入库时快照继承博主当时的标签。
- 博主改标签只影响后续新文章；不批量追改已有文章。
- 旧文章在首次启用时以当前博主标签建立一次快照。
- 文章可独立编辑标签，空数组代表明确清空；抓取更新不覆盖人工编辑。
- 标签按原大小写保存，去首尾空白、规范化 Unicode 并去重。
- 多选标签为且（AND）：文章必须同时包含全部所选标签。
- 标签与平台、博主、未读筛选及时间正序/倒序可组合。
- 未知发布时间仍显示未知，不用抓取时间冒充原始发布时间。

## 已读与观看历史

- 点开原文/文章标题或阅读器时记录打开；并同步 Miniflux 已读状态。
- 文章卡片右上角有未读发光点；保存为已读后消失。
- “未读”视图只显示未读文章；点开保存成功后从当前未读列表移除。
- 可手动设回未读；手动改状态不伪造观看历史。
- 同一个打开事件使用唯一 ID；重试不重复计数，再次打开是新事件。
- 编辑标签、浏览列表、刷新来源、页面预取不算阅读。
- “读了”按用户定义是点开，不声称检测了外站停留时间或读完全文。
- 原文打开后状态写入失败时显示错误并恢复未读提示，不假装保存成功。
- 浏览器通过右键菜单执行的外部动作无法可靠识别，不擅自将打开菜单视为已读。

## 后台

- 活跃度：过去365天的每日打开次数、独立文章数、活跃天数；按用户保存时区统计。
- GitHub风格色阶网格支持鼠标悬停、键盘聚焦与点击日期说明，移动端可横向滚动。
- 观看历史：时间倒序、游标分页，显示标题、博主、平台与打开时间，可再次打开。
- 活跃度从本功能记录开始；不能把以前的已读条目回填成虚构观看日期。
- 更新异常：展示缺通道、授权失效、访问受限、超时、上游错误和过期未检查等。
- 超时或元信息缺失不能直接定性“原文永久删除”；这里不批量扫描全部外部文章。
- 后台只读取现有采集状态；用户主动点“检查更新”才提交对应博主的检查请求。
- 不向后台暴露 Cookie、Feed 内部带令牌地址、数据库配置或其他服务环境变量。

## 存储与权限

复用 Bridge 私有 SQLite 的 settings 保存标签快照和手动覆盖；复用 audit 保存打开事件。
这些数据随完整 Bridge 备份恢复，不放入 GitHub，不建立第二份可编辑正文或高亮主库。
Miniflux 仍保存已读状态；本地记录只防止较早发出的同步响应覆盖更新后的状态。
所有标签写入、历史、活跃度和异常接口使用现有鉴权与跨站写入保护。
已有来源数量、标签关系、正文、文章ID及笔记ID不删除，未改上游应用数据库。
