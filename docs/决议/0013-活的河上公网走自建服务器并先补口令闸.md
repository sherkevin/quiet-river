# 0013 活的河上公网走自建服务器，并先补访问口令闸

状态：Accepted（2026-09-16）

## 背景

需求是「手机在任意网络下打开同一条**活的**河」：能刷新、能添加、能改 tag，而不是某一刻的快照。候选形态有四档，各自的前提在这台机器上逐一验过：

- **同一局域网**：`HOST=0.0.0.0` 即可，但出不了家门。
- **内网穿透**（ssh -R / tailscale / cloudflared）：河是活的，但本机实测两条路都不顺——`trycloudflare.com` 与 `lhr.life` 被公司办公网的域名策略拦截（返回中文 403 拦截页），tailscale 客户端未登录且其 CLI 被同一策略杀掉。隧道地址还是一次性的，手机上的书签会失效。
- **GitHub Pages 快照**：只读，已存在（0009 之后的产物），解决「给别人看」，不解决「自己随时看活的」。
- **自建服务器**：一台有公网 IP 的小机器跑服务本体。

## 决策

1. **活的河上公网 = 部署到用户自己的 ECS**，用 `tools/deploy-ecs.sh` 一条命令完成（workbench CLI 免 SSH 密钥直连）。Mac 继续当全功能原机：登录态源（知乎、小红书）的凭证与私有适配器只留在 Mac 上，服务器上没有它们。
2. **公网暴露之前必须先有访问口令闸**（`lib/access.js`）：这个应用没有账号体系，任何连上端口的人都能写。闸的形态是「口令换一年期 HttpOnly cookie」，浏览器走 `POST /login` 表单，也保留 `?token=` 一次性登录（用完 302 掉，不留地址栏）。不设口令时行为与从前完全一致，本机自用零负担。
3. **不给回环地址做豁免。**  tempting 但错：本项目的部署形态之一是 `ssh -R` 反向隧道（README「在别的设备上看这条河」第二节），那种形态下远端客户端的连接在服务端看来**就是回环**，豁免回环等于豁免了隧道用户。TCP 层的不可伪造性救不了应用层的形态多样性。所有人输一次口令，存一年。

## 理由

- 服务器形态下抓取出口是机房 IP。匿名源无所谓；登录态源在机房 IP 上更容易触发平台风控，所以它们**不上服务器**，停在快照时刻——这与 `docs/deploy-parity.md` 的既有结论一致，不是新妥协。
- 隧道形态的命门不在技术而在网络策略：公司办公网拦隧道域名，家里宽带拦不拦不知道，手机蜂窝网络更不可控。自建服务器是唯一「出口和入口都归自己」的形态。
- 口令闸选 cookie 而不是每次带 token，是因为手机浏览器不会替你保存 `?token=`；选一年期是因为这条河要天天开。

## 后果

- 新增运维面：systemd unit、专用用户 `qr`、`/etc/quiet-river/env`（0600）。脚本 `tools/deploy-ecs.sh` 固化了三个踩过的坑：macOS tar 的 `._*` AppleDouble 垃圾、非 root 监听 80 需要 `CAP_NET_BIND_SERVICE`、安全组默认不放 80 时表现为「握手成功但响应为空」。
- 大陆地域 ECS 的 80/443 受 ICP 备案约束，未备案可能被边缘拦截；脚本支持 `QR_ECS_PORT` 换非标准端口规避。
- **实测修订（同日）**：未备案时 80 端口的拦截表现是**公网直连超时丢包**（手机 `ERR_TIMED_OUT`），不是可见拦截页；而带透明代理的办公网出口却能拿到 200，两种观测互相矛盾，极易把假 200 当成部署成功。注意「在 ECS 上 curl 自己的公网 IP」也不是证据：那走 hairpin，不经过边缘拦截。可信的第三方出口是 GitHub Actions 探针（`.github/workflows/probe.yml`）。
- **再修订（同日稍后）**：各网络的放行策略互相矛盾且无法同时满足——办公网代理只放 80、运营商网放 4321 拦 80、境外两者都通。与其选边，服务端**同时监听 80 与 4321**（`PORT` 逗号列表），每种网络各取能通的那个；某端口被某网络拦只影响那条路径，服务端无感。ECS 上另常驻 cloudflared 隧道（`qr-tunnel` unit）作第三路径：走 Cloudflare 边缘 443，不碰备案；quick tunnel 地址重启会变，是它的代价。
- 服务器上的河是「匿名源活 + 登录态源快照」的混合体，问题栏会长期挂着知乎/小红书的缺凭证提示——这是预期形态，不是故障。
- 口令一旦设上，**所有**入口都要过闸，包括本机标签页与 CI 式的 curl 自检；README 与启动横幅都会提示。
